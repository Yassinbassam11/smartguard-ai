## 4. Asset Standards

Status: Complete through Choice C

The project uses Choice C: a custom internal credit system.

- `securityCredits` tracks balances.
- `balanceOf(address)` returns user credit balance.
- `transferCredits(address,uint256)` transfers credits securely.
- Credits are awarded when a user requests an audit.
- `spendCreditsForAdvancedAudit(uint256)` spends credits to unlock the advanced AI audit/report service.
- `spendCreditsForPdfReport(uint256)` spends credits to unlock a human-readable PDF report.
